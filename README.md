# Wanstar GitHub Pages

这个仓库部署的是万思达 Wanstar 项目展示网站。

- 根目录的 `index.html` 和 `assets/` 是已经构建好的 GitHub Pages 静态站点，保证页面可以直接访问。
- `website-source/` 是完整 React + TypeScript + Vite + Tailwind 源码，对应本地 `http://localhost:5173/` 的展示网站。
- `.github/workflows/deploy.yml` 可用于后续通过 GitHub Actions 从源码自动构建并部署 Pages。

本项目展示的是“基于 Cells 人格模拟技术的数字化身认知互联平台”，用于投资人/合作方理解 Wanstar 的技术逻辑、产品逻辑和 C-A-A-C 商业闭环。
